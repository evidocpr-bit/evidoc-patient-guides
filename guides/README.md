# Каталог памяток

Проверенные медицинские материалы пока не опубликованы. Ниже — структура будущей библиотеки.

| Каталог | Направление |
|---|---|
| `dermatology/` | Дерматология |
| `gynecology/` | Гинекология |
| `endocrinology/` | Эндокринология |
| `neurology/` | Неврология |
| `psychiatry/` | Психиатрия |
| `proctology/` | Проктология |

Файл памятки добавляется после проверки врачом. Каждый материал содержит дату проверки, имя рецензента, версию, источники и сведения об иллюстрациях. Черновики и персональные данные пациентов здесь не хранятся.
